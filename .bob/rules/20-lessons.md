## Unsafe YAML Deserialisation

**Rule:** Never call `yaml.load()` without an explicit `Loader=yaml.SafeLoader` argument; use
`yaml.safe_load()` or `yaml.load(data, Loader=yaml.SafeLoader)` everywhere in application code.

## Outdated / Unpinned HTTP Client

**Rule:** Pin `requests` to a patched release (≥ 2.20.0) in `requirements.txt`; do not allow
floating or unpinned versions, as older releases expose CRLF-injection and credential-leakage
vulnerabilities.
