# Lessons Curator

Reads the gate ledger and Bob task log, identifies recurring root causes across runs, and writes or
updates `.bob/rules/20-lessons.md` with actionable rules citing the evidence.

## Steps

1. **Read the ledger.**
   Open `sample-app/.gatekeeper/ledger.jsonl` — each line is one gate run.
   Collect: `ts`, `gate`, `version`, and `reasons[]`.

2. **Read the Bob task log.**
   Open `sample-app/.gatekeeper/bob_tasks.jsonl` — each line is one Bob task outcome.
   Collect: `timestamp` and `gate`.

3. **Identify recurring BLOCK reasons.**
   For each unique `reason` string that appears in multiple BLOCK runs, record:
   - The CVE / GHSA id and package name.
   - The severity (CRITICAL / HIGH / MEDIUM / LOW).
   - The list of `ts` timestamps from ledger runs where it was present.
   - The root cause pattern (e.g. unsafe deserialisation, unpinned/outdated HTTP client,
     known RCE gadget, etc.).

4. **Map root causes to rules.**
   Group findings by root cause pattern. For each pattern derive a concise, actionable rule:
   - **unsafe deserialisation** → never call `yaml.load()` without `Loader=yaml.SafeLoader`
   - **unpinned / outdated HTTP client** → pin `requests` to a version ≥ the first patched release
   - Add analogous rules for any other patterns found.

5. **Write `.bob/rules/20-lessons.md`.**
   Use `write_file` (or `apply_diff` if the file already exists) to produce a Markdown file with
   the following structure — one H2 section per root cause, a one-sentence rule, and a *Evidence*
   sub-list citing the gate timestamps:

   ```markdown
   # Lessons Learned

   > Auto-generated by lessons-curator from gate ledger. Do not edit by hand.

   ## <Root Cause Label>

   **Rule:** <actionable one-sentence rule>

   *Evidence (gate runs):* <timestamp1>, <timestamp2>, …
   ```

   Keep the file concise: one rule per section, no prose padding.

6. **Report.**
   Print a 5-line summary: number of BLOCK runs analysed, number of PASS runs, number of unique
   root causes identified, the rule file path, and the highest-severity finding.
